# 模型分稳定性与客群变化页面

## 展示范围

重构 Risk BI 的“模型分稳定性变化”和“客群变化”两个页签。页面读取 MyWorkflow 已发布到 DuckDB 的结果，不触发上游查询或模型计算。

- 保留业务环节、客户类型、产品、服务节点与目标变量筛选。
- 当前业务环节内选择主模型；可增加三个对比模型，总计最多四个。
- 稳定性可选择分析周及基准周，默认最近有成熟分箱的周。
- 客群默认展示近 15 天，可选择近 7／15 天、日／周粒度、原始十组或相邻合并五组分箱、对比基准期。
- 两个页签复用同一份分箱结果；请求缓存包括分区、生成时间、业务筛选、模型、目标及刷新版本。查询请求使用序号，防止旧响应覆盖新选择。

## 主模型切换（2026-10-12）

- 稳定性和客群变化的图表区提供“主模型”下拉框，列出当前已应用业务场景下有有效分数的模型，显示模型名和字段名。
- 主模型选择即时生效，更新主模型图表、比较曲线和样本范围，不需要再次点击“查询”。两个页签共享选择。
- 本次页面使用期间，按业务环节、客户类型、产品、服务节点组合分别记住主模型；切换目标变量保持同一场景的选择。再次回到该场景时恢复选择。
- 初次进入沿用效果页所选可用模型；未指定时默认选当前业务环节覆盖量最高的模型。旧选择不再可用时回到可用的默认模型。
- 效果页的模型筛选与图表区主模型选择分别管理，切换主模型不会把效果页的“全部模型”变成单模型。
- 侧栏只保留“模型分监控”入口；具备模型分监控权限的用户使用原 `?page=stability` 链接时，进入该页面的稳定性页签，不展示旧的示例稳定性页面。角色权限沿用现有配置。

## 口径与限制

- Q1 为低分段，Q10 为高分段，不给模型假定统一风险方向。不同模型和筛选组合独立分箱；相同 Q 标签不代表相同原始分值或相同客户。
- 日客户量已去重；周量按实际观察日累加，标记为人次，不宣称跨日去重人数。窗口首尾周可能不足七天，样本范围卡展示实际观察天数。
- 五组分箱仅合并相邻两组的已发布客户量；日转周后按累计分箱量／累计总量展示占比，不平均日百分比。
- 坏账率沿用每箱到期样本至少 100 的规则；未成熟结果留空，不补零、不连线。比较模型缺少当前期时不使用别的日期替代。
- 页面仅对已聚合结果做图表呈现、计数加总和基准差值；没有新增 PSI、分箱边界或其他业务计算。
- 原始观察窗口约一个月，无法从该结果诚实展示更长季度趋势；不拼接采用不同分箱的历史分区。
