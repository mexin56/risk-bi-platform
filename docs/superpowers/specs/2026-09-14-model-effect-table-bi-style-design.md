# 模型效果监控表格 BI 视觉优化设计

## 背景

模型效果监控首版已经具备业务环节、目标变量筛选，以及按周展示 `count`、`badrate`、`AUC`、`KS` 的能力。当前页面过于接近原始黑框表格，需要提升信息层级和日常使用的可读性。

## 目标

在不改变数据接口、计算逻辑和指标口径的前提下，将模型效果表格优化为正式 BI 监控页面风格，并继续保留参考图中的核心结构：筛选器、模型编码/名称、日期分组和四项指标。

## 设计方案

### 筛选工具条

- 使用浅灰背景的紧凑工具条承载“筛选器”、业务环节、目标变量和查询按钮。
- 查询按钮保留黄色作为页面主操作色，避免改变用户已确认的视觉识别。
- 刷新数据作为次级操作，与查询操作分离。
- 保持筛选先编辑、点击“查询”后应用的现有交互。

### 表格结构

- 继续使用两层表头：第一层为周起始日，第二层为 `count`、`badrate`、`AUC`、`KS`。
- 日期分组使用浅蓝灰背景，指标子表头使用更浅的灰蓝背景，强化层级。
- “模型编码”和“模型名称”列固定在左侧；周度数据区域支持横向滚动。
- 固定列采用白底和右侧轻阴影，滚动时保持模型身份可见。
- 表格使用细边框和隔行底色，取消沉重的纯黑粗框；行悬停时使用浅蓝色高亮。

### 指标展示

- 模型编码和名称左对齐，数值列右对齐并使用等宽数字。
- `count` 使用千分位；`badrate` 使用百分比；`AUC`、`KS` 保留三位小数。
- AUC/KS 的状态色只使用轻量背景或文字色，不使用大面积标签，避免表格视觉噪声。
- 无数据或成熟度不足继续留空，底部保留当前口径说明。

## 不在本次范围

- 不修改模型效果后端查询、周度聚合、成熟度判断和接口字段。
- 不新增趋势图、分页、导出或新的筛选维度。
- 不调整统一应用壳层、导航权限和其他监控页面。

## 验收标准

- 默认页面能看到筛选工具条、两层表头和模型效果数据。
- 左侧模型编码/名称在横向滚动时仍可识别。
- 日期组与四项指标层级清晰，表格在浅色背景下可读且不显得拥挤。
- 查询、刷新数据和现有 alias/target 筛选行为保持不变。
- 现有模型监控专项测试、前端 lint、生产构建和浏览器核验通过。
