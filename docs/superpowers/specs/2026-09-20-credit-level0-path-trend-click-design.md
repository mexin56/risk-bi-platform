# 授信归因 Level0 路径趋势点击修复设计

## 背景

授信归因页面中，`device_brand=sun_king` 属于 Level0 路径，后端已经存在完整的近 60 天趋势数据，但前端将 Level0 路径渲染为普通文本，用户无法选中该路径查看趋势。

## 目标

让授信归因表格中的 Level0“异常归因路径”与其他路径一样可点击，并复用现有路径选择和趋势加载逻辑。点击后应以被点击记录自身的 `id` 请求趋势数据。

## 方案

仅调整 `src/pages/CreditAttribution.tsx` 的路径列渲染：取消 Level0 与其他等级之间的可点击分支差异，统一使用现有的 `selectAlertPath(record)` 按钮和样式。

不修改后端接口、数据存储、状态统计、资金归集页面或趋势计算逻辑。这样可以将改动限制在表现层，并保持已有的路径选中、请求取消/覆盖和趋势展示流程不变。

## 数据流

1. 用户点击 Level0 路径。
2. 页面调用 `selectAlertPath(record)`，更新选中记录并触发趋势请求。
3. 现有 effect 使用选中记录的 `id` 和当前 `pt` 调用 `/api/credit-attribution/path-trend`。
4. 趋势卡片校验返回的 `record_id` 与选中记录一致后展示近 60 天数据。

## 验证

- 增加一个前端回归测试，确认 Level0 路径渲染为可点击控件，并触发记录选择回调。
- 执行前端测试和构建。
- 使用 `pt=20260919` 在页面验证 `device_brand=sun_king` 的趋势请求使用其自身记录 ID，而不是之前默认选中的子路径 ID。

## 非目标

- 不改变趋势数据的计算范围或后端接口。
- 不调整表格排序、筛选、状态标签和行点击行为。
- 不修改资金归集监控页面。
