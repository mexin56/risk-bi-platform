# 资金归因结果区 Tab 设计

## 目标

在资金归因页面的“合并预警结果”内容区内增加同级 Tab，使用户在预警结果和大盘日趋势之间切换。保持授信归因页面已有的 Tab 交互和资金归因现有数据接口，不改变计算逻辑、缓存结构或后端接口。

## 交互与展示

- 默认 Tab 为“合并预警结果”。
- “合并预警结果”保留现有规则处理状态子 Tab、数量徽标、表格、选中路径分析和状态操作。
- “大盘日趋势”复用 dashboard 返回的 `daily_trend`：
  - 每日异常订单使用柱状图；
  - 每日异常率使用折线图和右侧百分比坐标轴；
  - 不展示总订单数柱状图，避免与本次需求混淆。
- 趋势图沿用当前主题色、ECharts 组件、日期格式化和 tooltip 样式；横轴使用当前返回的完整日期范围。
- dashboard 加载失败、无数据和刷新行为保持现有逻辑。

## 实现边界

- 仅修改 `src/pages/FundAttribution.tsx` 及其前端测试；不改 API、后端计算和数据存储。
- Tab 状态为页面内状态，不新增 URL 参数或持久化字段。
- 测试覆盖默认 Tab、Tab 切换，以及趋势图的柱状/折线系列配置。
