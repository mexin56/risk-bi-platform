# CashJY 特征取数 SQL 生成器设计

## 目标

提供一个可重复运行的 Jupyter Notebook，从“特征重要性” Excel 表读取变量名和来源表，生成与现有 ml-platform 模板一致的特征取数 SQL，同时导出字段映射和告警清单。

## 设计

- 输入：用户指定的 `.xlsx` 文件和“特征重要性”工作表。
- 参数：主表名、主表别名、基础字段、关联键、分区字段、分区占位符、特征集名、数据集名、模型筛选条件和输出目录。
- 来源：使用 `table` 列作为来源表；单元格中以逗号分隔的多个表会拆成多个候选来源。
- 别名：来源表按 Excel 中首次出现的顺序分配 `t1、t2...`；同名字段保留首次出现的原名，后续出现按 `_v1、_v2...` 命名。
- SQL：每张来源表生成一个带 `cid、pt` 和特征列的子查询，并用 `left join` 按配置的关联键连接主表。
- 审核：输出来源表统计、同名变量、同一行多来源变量、重复 Excel 行和缺少变量/来源的告警。
- 输出：在 Notebook 展示 SQL，并保存 `.sql`、字段映射 `.csv`、告警 `.csv` 和来源表统计 `.csv`。

## 非目标

- 不连接数据仓库、不执行生成的 SQL。
- 不修改原始 Excel。
- 不推断真实主表字段；基础字段和关联条件由用户在参数单元格核对后配置。

## 验证标准

Notebook 可从头到尾执行；默认 Excel 路径可读取；SQL 包含参数化分区条件、每个来源表的 join、同名字段别名和告警注释；导出的 CSV 能追溯每个输出字段的来源。
