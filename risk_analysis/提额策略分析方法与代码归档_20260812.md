### 1.3 策略格映射

策略表行键为：

```text
客户类型 × 额度使用率 × 借款数 × 评分档位
```

| 线上字段 | 映射规则 |
|---|---|
| `jq_customer_flag` | `HAVE_SINGLE_LOAN` → 有单期借款；`HAVE_SINGLE_NOLOAN` → 无单期借款；`NO_SINGLE` → 无单期 |
| `defq_use_rate_level` | `1/2/3` → 高/中/低额度使用率 |
| `separate_installment_loan_cnt` | 1–6 各自匹配；**策略表行 7 代表借款数 7 及以上** |
| `jq_mix_score_bin` | `5/4/3/2/1` → `A/B/C/D/E` |

核心映射代码（`analyze_deployed_coefficient.py`）：

```python
def lookup_key(customer, use_rate, loan_count, score):
    customer_name = CUSTOMER_MAP.get(normalized_code(customer))
    use_rate_name = USE_RATE_MAP.get(normalized_code(use_rate))
    score_name = SCORE_MAP.get(normalized_code(score))
    count = min(max(1, int(float(loan_count))), 7)  # 7 = 7及以上
    if not customer_name or not use_rate_name or not score_name:
        return None
    return customer_name, use_rate_name, count, score_name
```

## 2. 逐行应统计的核心指标

每个策略表行新增以下聚合列：

### 2.1 提额与额度

| 指标 | 计算口径 |
|---|---|
| 提额客户数 | `te_flag=1` 的客户数 |
| 未提额客户数 | `te_flag=0` 的客户数 |
| 提额覆盖率 | 提额客户数 /（提额客户数 + 未提额客户数） |
| 提额客户提额前/后平均额度 | 各自在提额客户内的 `jq_credit_quota` / `cash_quota_amount_now_after` 均值（元） |
| 提额客户实际提幅（加权） | `SUM(后额度 - 前额度) / SUM(前额度)`，仅 `te_flag=1` |
| 未提额客户提额前/后平均额度 | 各自在未提额客户内的前/后额度均值（元） |
| 结清客户提额前/后平均额度 | 提额、未提额客户合并后的前/后额度均值（元） |
| 结清客户额度提升率 | `(结清后均额 - 结清前均额) / 结清前均额` |

### 2.2 策略是否执行

| 核验 | 判定 |
|---|---|
| 提额客户执行符合 | `te_flag=1` 且 `cash_quota_amount_now_after > jq_credit_quota` |
| 未提额客户执行符合 | `te_flag=0` 且 `cash_quota_amount_now_after = jq_credit_quota` |
| 行级执行符合率 | `(提额标签且实际提额人数 + 未提额标签且实际未变人数) / 行内有效客户数` |

> `te_flag` 与额度变化验证“是否按提额/未提额标签执行”；它与系数表是否一致是两项不同的核验。

### 2.3 线上系数与策略表比对（已按最终口径修订）

- **线上配置系数分布字段：`cash_remark1`**，业务含义为线上提额幅度。
- **只统计 `te_flag=1`（满足提额条件）客户**：
  - 满足提额条件客户线上配置系数分布：该客户群内 `cash_remark1: 人数`。
  - 满足提额条件客户线上系数一致客户数：`abs(cash_remark1 - 策略表目标系数) < 1e-10` 的人数。
  - 满足提额条件客户线上系数一致率：

```text
线上系数一致客户数
÷
(线上系数一致客户数 + 线上系数不一致客户数)
```

- **未提额客户不参与**线上系数一致客户数、不一致客户数或一致率。
- `te_flag=0` 但 `cash_remark1>0` 的客户单列为“正系数但未提额客户数”，需要结合资格、拦截、封顶、白名单等原因码解释；不自动判定为标签执行错误。

### 2.4 发起与贷后表现

| 指标 | 口径 |
|---|---|
| 提额/未提额客户 T0 发起率 | `next_curday_flag=1 / 对应客户数` |
| 提额/未提额客户下一笔发起率 | `next_loan_flag=1 / 对应客户数` |
| FPD1/7/15/30 | 客户口径：`fpdX_fz_dd / fpdX_fm_dd` |
| FPD 样本数 | 对应 `fpdX_fm_dd` 分母，必须与 FPD 比率一起展示 |

> 当前是上线首日结清批次，FPD 成熟样本较少。可展示监控值，但不可仅根据当前小样本 FPD 对策略作稳定风险结论。

## 3. 整体达成测算方法

在全部有效结清客户上汇总逐行结果：

```text
提额前户均额度 = SUM(提额前额度) / 有效结清客户数
提额后户均额度 = SUM(提额后额度) / 有效结清客户数

实际总增额 = SUM(提额后额度 - 提额前额度)
达标所需总增额 = (50,000元 - 提额前户均额度) × 有效结清客户数
目标增量达成率 = 实际总增额 / 达标所需总增额

提额前目标达成率 = 提额前户均额度 / 50,000元
提额后目标达成率 = 提额后户均额度 / 50,000元
```

## 4. 核心 SQL（只读聚合）

主脚本将以下结果按策略维度、`cash_remark1`、`te_flag` 聚合，再在 Python 中映射至策略表每行：

```sql
SELECT
  jq_customer_flag,
  defq_use_rate_level,
  separate_installment_loan_cnt,
  jq_mix_score_bin,
  cash_remark1,
  te_flag,
  COUNT(1) AS cnt,
  SUM(CAST(jq_credit_quota AS DOUBLE)) AS before_sum_cent,
  SUM(CAST(cash_quota_amount_now_after AS DOUBLE)) AS after_sum_cent,
  SUM(CAST(cash_quota_amount_now_after AS DOUBLE)
      - CAST(jq_credit_quota AS DOUBLE)) AS increment_sum_cent,
  SUM(CASE WHEN CAST(cash_quota_amount_now_after AS DOUBLE)
             > CAST(jq_credit_quota AS DOUBLE) THEN 1 ELSE 0 END) AS actual_raise_cnt,
  SUM(CASE WHEN CAST(cash_quota_amount_now_after AS DOUBLE)
             = CAST(jq_credit_quota AS DOUBLE) THEN 1 ELSE 0 END) AS actual_unchanged_cnt,
  SUM(CASE WHEN CAST(next_curday_flag AS BIGINT) = 1 THEN 1 ELSE 0 END) AS t0_cnt,
  SUM(CASE WHEN CAST(next_loan_flag AS BIGINT) = 1 THEN 1 ELSE 0 END) AS next_loan_cnt,
  SUM(CAST(fpd1_fz_dd AS DOUBLE)) AS fpd1_num,
  SUM(CAST(fpd1_fm_dd AS DOUBLE)) AS fpd1_den,
  SUM(CAST(fpd7_fz_dd AS DOUBLE)) AS fpd7_num,
  SUM(CAST(fpd7_fm_dd AS DOUBLE)) AS fpd7_den,
  SUM(CAST(fpd15_fz_dd AS DOUBLE)) AS fpd15_num,
  SUM(CAST(fpd15_fm_dd AS DOUBLE)) AS fpd15_den,
  SUM(CAST(fpd30_fz_dd AS DOUBLE)) AS fpd30_num,
  SUM(CAST(fpd30_fm_dd AS DOUBLE)) AS fpd30_den
FROM pb_biz_credit.flexi_cash_jq_result_v1
WHERE jq_date = '2026-08-12'
  AND str_type = 'new'
  AND CAST(jq_credit_quota AS DOUBLE) >= 0
  AND CAST(cash_quota_amount_now_after AS DOUBLE) >= 0
GROUP BY
  jq_customer_flag, defq_use_rate_level, separate_installment_loan_cnt,
  jq_mix_score_bin, cash_remark1, te_flag;
```
